# Crédits et provenance

- **Cours et classe Vehicle** : Michel Buffa (`micbuffa`), projet pédagogique de steering behaviors fourni par l’utilisateur. `source/vehicle.js` est une copie intégrale de `3-Arrival_correction/vehicle.js` au commit `9104084` de l’historique fourni. Son contenu et ses commentaires sont conservés. Aucune licence nouvelle n’est attribuée à ce code pédagogique.
- **Comportement 6 modifié** : version fournie par l’utilisateur dans la pièce jointe `4209b19f-8ac8-4e20-bc71-ea602ba4c247`, archive complète incluse. L’extraction de son calcul est identique et testée.
- **p5.js 1.7.0** : p5.js contributors / Processing Foundation. Fichier embarqué copié depuis les bibliothèques du cours. [Projet officiel](https://github.com/processing/p5.js/tree/v1.7.0), [licence LGPL-2.1](https://github.com/processing/p5.js/blob/v1.7.0/license.txt). La bibliothèque est conservée sans modification, avec son en-tête de version.
- **Référence théorique** : Craig W. Reynolds, *Steering Behaviors For Autonomous Characters*, GDC 1999. Le jeu réutilise les implémentations du cours.
- **Audio original ASTRA** : 2 couches musicales et 13 effets synthétisés pour le jeu par `source/generate_audio.py`, sans échantillon ni enregistrement tiers. Les 15 WAV sont dans `assets/audio/`, sous CC0-1.0 avec leur [licence](assets/audio/LICENSE.txt). Leur copie intégrée `js/audio-data.js` porte la même licence. Ils peuvent être publiés avec le dossier sur GitHub.
- **Direction artistique, interface et logique de jeu** : créées pour ASTRA Squadron. Avions, étoiles, planète, astéroïdes et effets dessinés par code. L’inspiration ZType concerne l’ambiance spatiale ; aucune ressource graphique, police ou bande sonore de ZType n’est incluse.

Les empreintes des deux sources de steering se trouvent dans `source/provenance.json`. La copie de ce dossier est techniquement autonome ; cette attribution conserve l’origine de chaque composant.
